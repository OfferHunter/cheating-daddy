# 海王AI面试助手（offer hunter）

## 写在前面

我们提供软件的安装版 portable 两个版本。可以双击exe进行安装，也可以解压压缩包直接使用。
我们提供软件的长期支持。如果有需求或者 bug 可以直接告诉客服，我们会提上日程！软件更新后仍在原下载链接发布。

- Q: 是否一定不会被捕获到？
- A: 这个软件通过 Electron 的 SetWindowDisplayAffinity 实现隐身。它不会被绝大多数屏幕捕捉方式拍到，包括截屏录屏、牛客 AI 面试、腾讯会议、飞书会议等等，但仍可能被底层方式抓取。如果你有特殊的面试软件，可以联系我们测试！

注意：一定要选用视觉模型，如deepseek-flash。deepseek-v4-pro 没有视觉，识图会失败。

首次运行需要输入激活码（软件绑定本机，见下方“激活说明”）。本软件提供两种提词方式：**纯电脑端提词**（一切在本机应用内完成）和**电脑+移动端提词**（用同一局域网中的手机或平板浏览器当显示屏，规避屏幕捕捉与离屏事件检测）。

### 激活说明

软件通过激活码绑定到具体的电脑，激活过程不需要联网。

1. 首次打开应用会进入激活界面，界面上会显示一串本机机器码。点右侧的复制按钮，把这串机器码发给客服。
2. 客服返回一段与这台机器对应的激活码。
3. 把激活码粘贴进输入框，点击“激活”。成功后进入欢迎页，点“继续”即可使用。

- 激活码与本机机器码一一对应，换另一台电脑需要重新获取。
- 激活码可能带有效期。激活后可在“帮助与支持”页面看到“已永久激活”或剩余时间。
- 报错含义：格式不对、激活码属于其他电脑、签名校验失败（多半是抄错）、激活码已过期（需向客服换新的）。

## 1. 产品介绍

海王AI面试助手（offer hunter）是一款用于面试、会议、演示等实时场景的桌面 AI 助手。

应用会同时采集系统播放声音和可选的麦克风声音，通过阿里云百炼或腾讯云进行实时语音识别（二选一，见“3. 怎么得到 API Key”），再把识别结果与会话上下文发送给兼容 OpenAI 接口的模型。默认配置使用 DeepSeek，也可以填写其他兼容服务的 Base URL、API Key 和模型名称。

主要功能包括：

- 实时识别面试官或会议中的系统音频，并自动生成回答。
- 可选采集麦克风，把自己已经说过的内容加入后续上下文；麦克风内容不会单独触发 AI 回答。
- 同时生成适合快速浏览的精要回答，以及可结合本地知识库生成的详细回答。
- 手动截取当前屏幕并向 AI 提问，适合分析代码、题目、图表或演示内容。
- 支持输入文字继续追问。
- 支持用手机/平板浏览器当第二块显示屏（“电脑+移动端提词”）：回答只出现在手机屏幕上，同时可在手机上控制截图、暂停和结束会话。
- 将会话、精要回答、详细回答和双方转录记录保存在本地历史中，支持全文搜索、导出和删除。
- 支持自定义提示词（可逐段覆盖系统提示词），以及用 Markdown 文件组成的本地知识库。
- 通过激活码绑定本机，无需联网激活即可使用。

窗口采用透明悬浮设计，支持主题、组件透明度和文字透明度调整。它可以保持置顶、用快捷键移动、隐藏或开启鼠标穿透，并启用了窗口内容保护，以降低助手窗口被屏幕截图或录屏捕获的可能性。

当前版本主要按 Windows 使用流程设计。项目保留 Electron 的跨平台结构和 macOS 音频辅助能力，但不同系统的音频权限及行为可能存在差异。

## 2. 用法流程

### 使用场景

面试官使用腾讯会议、飞书会议或企业专属会议软件等在线方式观看面试者的电脑屏幕，并通过扬声器/麦克风与面试者交流，时不时展示一些题目画面。此软件可以在除拍屏外的绝大多数屏幕截取方式中隐身，从系统播放音频得到面试官语音、从麦克风得到面试者语音、从屏幕中获得题目信息，即时对面试官的问题提供回答。

如果担心电脑端仍被网页/会议软件从快捷键、离屏事件等侧信道察觉，可以用“电脑+移动端提词”，让回答只出现在同一局域网中的手机或平板屏幕上。

纯笔试场景同样适用本软件。

### 选择提词方式

主页顶部用左右箭头在两种提词方式之间切换：

| 方式           | 说明                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------- |
| 纯电脑端提词   | 采集、识别、回答都在本机应用窗口内完成。方便，但部分网站可能从快捷键、离屏事件或离屏率察觉。      |
| 电脑+移动端提词 | 回答通过局域网推送到手机/平板浏览器，屏幕上不出现助手窗口，规避屏幕捕捉、快捷键记录和离屏检测。 |

选择“电脑+移动端提词”时，主页会显示配对信息：

- **地址**：形如 `http://192.168.x.x:8765` 的局域网地址，点“复制链接”复制。
- **配对码**：6 位数字，点“重新生成配对码”可换一个。
- **状态**：显示“手机已连接”或“等待手机连接…”。

把地址在**同一 Wi-Fi 下的手机浏览器**里打开，输入配对码即可连接；配对成功后手机浏览器会记住这台电脑，无需每次重输。**未连上手机时“开始会话”不可点击**——此模式下手机才是显示端。

手机页面上可以看到精要/详细/兼有三档视图、逐条跳转的导航条、以及“截图”“暂停”“清空上下文”“结束会话”按钮。手机上的“结束会话”只结束当前会话并让电脑回到主页，**不会退出电脑上的程序**——手机误触不该杀掉电脑端的应用。分辨率更大的平板会自动提供左右分栏（兼有）视图。

### 开始会话

1. 首次使用先完成激活（见“写在前面”）。
2. 进入“API 配置”页：填写对话模型的 Base URL、API Key 和模型名称。
3. 在“API 配置”页的语音识别区，用左右箭头在**阿里云百炼**和**腾讯云**之间翻页，勾选“使用”选中要用的那一家，并填好该家的凭据：
   - 百炼：API Key、WebSocket 地址、识别模型、语音语言。WebSocket 默认使用华北 2（北京）公共地址，默认模型为 `fun-asr-realtime-2026-02-28`。
   - 腾讯云：AppID、SecretId、SecretKey，语音语言用引擎型号选择。
   两家都可以各自填好，会话只用勾选的那一家。页内还提供“测试识别”，选麦克风或扬声器（面试官）实时验证识别是否可用。
4. 如有需要，进入“AI 上下文”，填写简历、岗位要求或其他背景信息，选择知识库目录，必要时展开“系统提示词”逐段调整。
5. 在“设置”中选择麦克风设备、回答方式、外观和快捷键。
6. Windows 11 需要在 设置 → 隐私和安全性 → 麦克风 中开启「麦克风访问权限」及「允许桌面应用访问麦克风」。
    Windows 10 需要在设置 → 隐私 → 麦克风，确认开启：「允许访问此设备上的麦克风」、「允许应用访问你的麦克风」和「允许桌面应用访问你的麦克风」。
    macOS 在首次使用麦克风时，系统通常会弹出授权提示，点击「允许」。如果之前拒绝过：系统设置 → 隐私与安全性 → 麦克风。
7. 回到主页，在顶部选好提词方式，然后点击“开始会话”。也可以在主页按 `Ctrl + Enter`（macOS 为 `Cmd + Enter`）。

会话开始后，应用会监听系统音频。识别到一句完整问题时，会在转录区显示面试官内容并生成 AI 回答。若启用了麦克风，你自己的话会显示在右侧并加入后续上下文，但不会自行触发新的回答。

### 精要回答和详细回答

- **精要回答**显示在实时转录区域，目标是尽快给出容易扫读、可以立即使用的回答。
- **详细回答**显示在右侧面板，对同一个问题给出更完整的内容，并可按需读取本地知识库。
- 详细回答面板可以拖动分隔线调整宽度，也可以用快捷键切换前一条或后一条详细回答。
- 在设置中关闭“显示详细回答侧栏”后，普通语音问题只生成精要回答；该选项从下一次会话开始生效。

### 截图提问

在会话页面点击“分析屏幕”，或按 `Ctrl + Enter`（macOS 为 `Cmd + Enter`），应用会截取当前屏幕并发送给支持图片输入的对话模型。

截图问题的回答只显示在详细回答面板中。应用还会并行生成一条简短的截图内容摘要，将它加入会话记录，方便后续问题继续引用截图中的信息。截图分析是否启用思考，由“截图回答启用思考”单独控制。

### 会话中的常用操作

- 在底部输入框输入文字并按 `Enter`，可以直接向 AI 发送补充问题。
- 会话顶部的暂停按钮会暂停当前音频处理；恢复后继续使用同一会话。
- “清除上下文”会清空当前会话在模型侧使用的历史上下文，不会删除本地历史。
- “结束会话”会停止本次采集、把当前会话收尾保存在本地历史中，并回到主页。已经识别出的麦克风末句也会保存。
- 历史记录页面可以搜索自定义提示词、面试官问题、用户转录、精要回答和详细回答中的内容。

## 3. 怎么得到 API Key

应用需要两类凭据：一个用于对话模型，一个用于实时语音识别。语音识别在**阿里云百炼**和**腾讯云**之间二选一。基于速度和智能的权衡，对话模型推荐使用 ```DeepSeek V4.1 Flash```；语音识别推荐阿里云百炼的 ```fun-asr-realtime```。预计一场一小时会议问答消耗在5元以内（语音识别几乎不花钱）。

### 对话模型（DeepSeek 或任意 OpenAI 兼容服务）

1. 注册并登录 [DeepSeek 开放平台](https://platform.deepseek.com/)。
2. 进入 [API Keys](https://platform.deepseek.com/api_keys) 页面创建新的 API Key。
3. 复制生成的 Key，粘贴到“API 配置”页的“API Key”输入框。
4. 默认 Base URL 为 `https://api.deepseek.com`。模型名称必须与 DeepSeek 当前提供的模型标识完全一致。
5. 确保账户已经开通 API 服务并有可用余额。

DeepSeek 使用 OpenAI 兼容接口，调用方法可参考 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/zh-cn/)。如果改用其他 OpenAI 兼容服务，需要同时替换 Base URL、API Key 和模型名称。截图提问要求模型支持图片输入。

### 语音识别服务：阿里云百炼或腾讯云（二选一）

两家都要在“API 配置”页的语音识别区用左右箭头翻页配置。**两家可以各自填好，但会话只使用勾选了“使用”的那一家**。各自的语音语言分开保存，因为两家支持的语种不一样。也可以填好一家的凭据后，用页内“测试识别”先验证一下。

#### 阿里云百炼

1. 注册并登录阿里云，开通百炼模型服务。
2. 前往[阿里云百炼控制台](https://bailian.console.aliyun.com/)，在 API Key 管理页面创建或复制 API Key。记得对阿里云百炼账号进行充值（1~2元即可开通模型使用，fun-asr系列1块钱可以用很久）。
3. 在“API 配置”页填写与 Key 属于同一地域和业务空间的 WebSocket 地址。默认值为北京公共地址 `wss://dashscope.aliyuncs.com/api-ws/v1/inference`（如果你在中国大陆就不用改）；也可以填写控制台提供的带 Workspace ID 的专属地址。
4. 把 Key 粘贴到“Bailian API Key”输入框。
5. 语音识别模型默认为 `fun-asr-realtime-2026-02-28`；除非确认其他模型兼容当前实时 ASR 协议，否则建议保留默认值。语音语言从下拉里选。

地域之间的 API Key、接入地址和可用模型不能混用。具体创建步骤及地域说明请参考：
- [阿里云官方 API Key 文档](https://help.aliyun.com/zh/model-studio/get-api-key/)。
- [百炼实时语音识别模型](https://docs.bailian.console.aliyun.com/zh/model-studio/real-time-speech-recognition-user-guide)

#### 腾讯云

1. 注册并登录腾讯云，开通语音识别服务。腾讯云支持国内外服务、每月有免费额度，用完后价格相对较高。
2. 进入[访问管理控制台](https://console.cloud.tencent.com/cam/capi)创建一对 SecretId / SecretKey；AppID 在[账号信息](https://console.cloud.tencent.com/developer)页面查看。
3. 在“API 配置”页翻到腾讯云页，填入 AppID、SecretId、SecretKey。腾讯云的**语音语言由引擎型号决定**（如 `16k_zh` 中文通用、`16k_en` 英文、`16k_yue` 粤语等），在下拉里按计费分档选择。
4. 点击腾讯云标题旁的“使用”勾选，把会话切到腾讯云。

腾讯云实时语音识别文档：[https://cloud.tencent.com/document/product/1093/48982](https://cloud.tencent.com/document/product/1093/48982)。

所有 Key / 凭据都会保存在本机应用配置目录中。请不要把真实凭据写入仓库、截图、日志或分享给其他人；怀疑泄露时应立即在对应平台删除并重新创建。

## 4. 设置详细说明

### 首页连接设置（API 配置页）

对话模型：

| 设置         | 说明                                                                             |
| ------------ | -------------------------------------------------------------------------------- |
| API Base URL | 对话服务的基础地址。应用会向 `<Base URL>/chat/completions` 发起请求。            |
| API Key      | 对话模型服务的访问密钥。                                                         |
| 模型         | 对话服务要求的准确模型名称。用于普通回答、详细回答和截图分析。                   |

语音识别（左右箭头在两家之间翻页，勾选“使用”的那一家生效）：

| 设置                     | 说明                                                                                                             |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| 使用（单选）             | 勾选即把会话切到这一家。取消勾选被忽略——总得有一家在用，另一页的勾会随之落下。                                  |
| 百炼 API Key             | 阿里云百炼实时语音识别使用的访问密钥。                                                                           |
| WebSocket 地址           | 百炼实时语音识别的完整 `wss://` 地址。默认使用北京公共地址，也可以填写控制台提供的 Workspace 专属地址。Key、地址和模型必须属于同一地域。 |
| 百炼模型                 | 百炼识别模型，默认 `fun-asr-realtime-2026-02-28`。该模型仅支持北京；使用其他地域时需要填写当地可用的模型名称。      |
| 百炼语音语言             | 百炼识别的语言提示（如中文、英文、日语…）。模型不支持的语种由服务端报错。                                        |
| 腾讯云 AppID            | 腾讯云账号信息页的 AppID（放进请求路径）。                                                                       |
| 腾讯云 SecretId / SecretKey | 腾讯云访问管理的密钥对，用于签名鉴权。                                                                       |
| 腾讯云语音语言           | 用引擎型号同时决定语言与方言（如 `16k_zh`、`16k_en`、`16k_yue` 等），按计费分档选择。                             |
| 测试识别                 | 选麦克风或扬声器（面试官）实时采集并显示识别结果，用来验证凭据和网络是否可用。与当前启用的是哪一家无关，翻到哪页就试哪一家。 |

### AI 上下文

| 设置                   | 说明                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| 系统提示词             | 折叠面板。可逐段覆盖精要回答、详细回答和通用规则的内置提示词；“恢复默认”清空全部覆盖。谨慎修改。 |
| 自定义指令（User Information Context） | 在会话开始时加入模型上下文，适合填写简历摘要、目标岗位、回答风格和限制条件。建议保持精简。 |
| 知识库目录             | 选择一个包含 `.md` 文件的本地目录。每个文件是一条知识记录，可预览或“显示文件”。            |
| `name` / `description` | Markdown frontmatter 中的名称和摘要会提供给模型，用来判断是否需要读取该文件。              |
| Markdown 正文          | 只有详细回答认为相关时才读取，避免每次请求都携带全部资料。                                 |

建议的知识库文件格式：

```markdown
---
name: 项目经历
description: 主要项目、职责和技术成果
---

这里填写完整内容。
```

### 音频输入

| 设置             | 说明                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| 扬声器（面试官） | 始终跟随 Windows 默认播放设备，用于识别对方声音并触发回答。                                      |
| 麦克风（我）     | 可关闭或选择输入设备。麦克风内容只补充上下文，不单独触发回答。                                   |
| 图像质量         | 控制截图发送给模型时的质量。质量越高，图中文字越清晰，但请求体也越大。                           |
| 语句静音时长     | 系统音频持续静音多久后结束一句并发送。值越低响应越快，但更容易把一句话拆开，需要权衡速度和质量。范围为 200–6000 ms。 |
| 我的语句静音时长 | 麦克风持续静音多久后结束一段自己的发言。通常应比面试官通道稍长，修改后从下一次会话生效。一般不用改。         |
| 扬声器门限       | 扬声器音量高于该 dBFS 值时忽略麦克风，减少对方声音串入自己的转录。`-80` 基本等于关闭门限。       |
| 扬声器门限保持   | 音量越过门限后，需要持续多久才切换麦克风静音状态。值越高越稳定，但响应更慢。                     |

所有音频在发送给语音识别服务前统一处理为 16 kHz 单声道 PCM。系统音频和麦克风使用独立识别连接及独立静音阈值。

### 语言

| 设置     | 说明                                                               |
| -------- | ------------------------------------------------------------------ |
| 界面语言 | 在中文和英文界面之间切换，默认中文。                               |

语音语言不在本页设置——它属于具体的识别服务，在“API 配置”页里按百炼、腾讯云分别设置（见上）。界面语言与语音语言相互独立。

### 回答

| 设置                 | 说明                                                                                                 |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| 显示详细回答侧栏     | 每个普通问题同时生成精要回答和详细回答。关闭后只生成精要回答；下一次会话生效。                       |
| 简短回答启用思考     | 允许精要回答先进行模型推理。质量可能提高，但首字等待时间更长。                                       |
| 详细回答启用思考     | 允许详细回答进行模型推理，默认关闭。                                             |
| 截图回答启用思考     | 只控制截图回答，默认开启。复杂图片的思考可能占用较长时间。                                           |
| 截图内容摘要         | 默认开启。开启时先用一个小请求把截图概括成一行文字，这行是它在历史里的显示、也是它之后在上下文里的唯一痕迹；关闭后不再发该请求，历史只显示“【屏幕截图】”，该轮也不会被回放给模型。截图本身的作答不受影响。下一次会话生效。 |
| 上下文轮数           | 每次请求回放给模型的历史轮数。值越高，上下文越完整，请求也越大、越慢。范围为 1–100，下一次会话生效。 |
| 最大 Token 数        | 单次回答的输出预算，模型思考也会占用该预算。过低可能导致正文为空；下一轮请求生效。                   |

### 隐私与数据

- **恢复全部设置**：恢复界面和功能开关的默认值，但保留自定义提示词和知识库目录。
- **删除全部数据**：删除本地配置、密钥、偏好、快捷键和历史记录，然后关闭应用。
- **历史记录管理**：可以多选会话，导出为 JSON 或从本地删除。搜索框会检索完整会话内容，而不只检索“求职面试”等会话类型名称。

#### 配置与历史记录保存位置

Portable 版和安装版使用同一套存储逻辑。Portable 版不会把用户数据写在程序所在目录，因此同一系统账户下的两种发行版会读取并修改同一套配置和历史记录。

| 系统    | 数据目录                                              |
| ------- | ----------------------------------------------------- |
| Windows | `%APPDATA%\offer-hunter-config`                     |
| macOS   | `~/Library/Application Support/offer-hunter-config` |
| Linux   | `~/.config/offer-hunter-config`                     |

Windows 中的完整路径通常为 `C:\Users\<用户名>\AppData\Roaming\offer-hunter-config`。该目录包含：

| 文件或目录              | 内容                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------- |
| `config.json`           | 初始化状态、窗口布局、对话接口地址、对话模型名称、启用的识别服务及其地址/模型/语言、手机提词端口与长效令牌等。 |
| `credentials.json`      | 对话模型 API Key、阿里云百炼 API Key，以及腾讯云的 AppID / SecretId / SecretKey。当前以明文 JSON 保存，请保护好系统账户和文件。 |
| `preferences.json`      | 界面语言、主题、透明度、回答方式、音频设置、自定义提示词（含系统提示词分段覆盖）和知识库目录等。 |
| `keybinds.json`         | 用户修改过的快捷键；尚未修改快捷键时可能不存在。                                      |
| `license.json`          | 本机的激活记录（机器码、激活码、是否永久或到期时间）。                                 |
| `history/<会话ID>.json` | 每次会话的转录、AI 回答及相关上下文。                                                 |

> 手机提词的长效令牌（`teleprompterToken`）保存在 `config.json`。它是局域网内的共享秘密，配对一次后手机不用再输码；API Key 与它无关，永远不出主进程。

默认值统一定义在应用内置的 `src/defaults.js` 中。应用首次启动或本地配置被清除时，会在上述目录创建配置文件并写入默认值；之后用户的修改直接写回对应 JSON 文件。知识库 Markdown 文件仍保存在用户选择的原目录中，应用只在 `preferences.json` 中记录其路径。

因此，移动或删除 Portable 程序、升级安装版以及通常情况下卸载后重新安装，都不会自动删除这些数据。若要彻底清除，请使用设置中的“删除全部数据”，或在应用退出后手动删除上述数据目录。

## 5. 如果你是开发者

本地开发运行：```npm install```+```npm start```。

本地生成二进制打包版：```npm run package```；生成二进制安装版：```npm run make```。

### 本地验证与工具

应用窗口默认带屏幕捕获保护、且实时视图不可聚焦，直接跑 `npm start` 很难截图或点击验证。仓库提供一批用隐藏 Electron 窗口加载真实页面、真实历史文件的离屏测试脚本（`scripts/` 下的 `*-harness.js`），结果写到文本文件里，改到对应界面时可以先用它们回归：

- `node scripts/defaults.test.js`、`node scripts/license.test.js` 等纯逻辑单测可直接用 node 运行。
- `npx electron scripts/teleprompter-harness.js`（设 `TP_HARNESS_OUT=<目录>` 指定输出目录，默认写到系统临时目录的 `tp-results.txt`）会加载真实的手机提词页并驱动真实事件流。

生成激活码（仅维护者）：配好 `.license-private/` 里的私钥后运行 `npm run license`。激活体系用 Ed25519 签名：源码公开，因此没有内嵌共享密钥，验签只用内嵌的公钥，签发在离线侧完成。

### 一键整理发布版本

安装依赖后运行 `npm run release`。命令按当前系统和 CPU 架构执行 package，再复用打包结果执行 make，同时生成便携 ZIP。全部成功后输出到：

```text
release/
├── README.md
├── offer hunter-<版本> Setup.exe # Windows 安装程序
├── offer hunter-win32-x64-<版本>.zip # Windows 便携版，完整解压后运行
└── Source Code/ # 源码包，可在别处重新构建
```

macOS 上按配置生成 DMG 和 ZIP。普通 Windows 用户只需要安装程序或便携 ZIP 其中之一。

源码包内含 `src`、`scripts`、构建配置与 LICENSE 等重新构建所需的内容。排除规则跟随 `.gitignore`：被 git 忽略的文件一律不打包，另外 `.gitignore` 自身与 `.git` 也始终排除。构建中间文件保留在 `out/release-build-*`。发布采用就地覆盖：只生成或覆盖同名产物，不会删除 `release` 目录里已有的其他文件，构建失败时不写入任何产物。
